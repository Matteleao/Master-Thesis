# House standards for all 24 instruments

Every review checks the instrument against this list. Status: MANDATORY = the user stated it; APPROVED = proposed and accepted by the user; PROPOSED = waiting for the user's decision (report compliance, do not fail on it). Never move an item to APPROVED without the user's explicit yes. Record the date.

| ID | Standard | Status | Since |
|---|---|---|---|
| S1 | The instrument header (acronym, full name) appears on every page. | MANDATORY | 2026-10-04 |
| S2 | Section A is always "Purpose and use". | MANDATORY | 2026-10-04 |
| S3 | The signature block is identical across all instruments and closes the controlled part of the document: two boxes, "<Document> owner" and "PI / accountable approver", each with "Name / role" and "Signature / date" (CCDM format; author 2026-10-06). Exception approved for individual records: TRE keeps four boxes (evaluator, supervisor, PI, person released), made larger (author 2026-10-08). Repeatable continuation sheets (for example extra task or log pages) may follow it, provided each sheet's header links it to the approved record: record ID, revision, effective date, sheet n of N. Nothing else follows the continuation sheet. | MANDATORY | 2026-10-04 (refined same day) |
| S4 | All instruments look alike: same palette, typography, header bar, section headers, table style. | MANDATORY | 2026-10-04 |
| S5 | No two tables in one instrument carry the same information. | MANDATORY | 2026-10-04 |
| S6 | Instruments reference only instruments in the 24-instrument set (or sponsor/site records named generically, e.g. "the study delegation log"). | PROPOSED | 2026-10-04 |
| S7 | CtQ domains are cited by thesis code and name (CtQ1-CtQ12, Table 3.2); spelling "CtQ". | PROPOSED | 2026-10-04 |
| S8 | Section A contains the purpose text plus a four-row table: unit of analysis, decision supported, inputs, outputs (mirrors Table 4.4). | PROPOSED | 2026-10-04 |
| S9 | Footer: "<ACR> v<x.y> \| <page content>" left, "Page n of N" right; version identical in file name, header and footer. | PROPOSED | 2026-10-04 |
| S10 | Simulated examples use a shoulder device investigation, in American English. | PROPOSED | 2026-10-04 |
| S11 | Every table row that another instrument must reference has an ID column. | PROPOSED | 2026-10-04 |
| S12 | Severity, criticality or restriction scales use the same color direction in every instrument: most restrictive or most critical = red, routine = green. | PROPOSED | 2026-10-04 (CCDM review) |
| S13 | Repeatable continuation sheets carry "Continuation sheet" in the footer and the sheet number in the header, never "Page n of N". | PROPOSED | 2026-10-04 (CCDM review) |
| S14 | The page-1 metadata block has the same core fields in every instrument. | NOT ADOPTED (author: DTRM header is fine as it is) | 2026-10-06 |
| S15 | Section titles in sentence case in every instrument. | PROPOSED | 2026-10-06 (DTRM review) |
| S16 | A "Next review / controlled location" box can be added next to the signature block in instruments where a scheduled review matters (not needed in DTRM; not used in RACI, which is event-driven). Consider it in each review. | NOTE FROM AUTHOR | 2026-10-06 |
| S17 | Shared IDs: an instrument that refers to tasks, functions or modules defined in another instrument uses that instrument's IDs (CCDM T01..., DTRM P-01... and MOD-01..., TRE record IDs) and never creates a parallel ID set. | PROPOSED | 2026-10-08 (RACI review) |
| S18 | No code collision: code letters and IDs of one instrument cannot be read as those of another (DTRM TR/AS/CD/AW/NA vs RACI R/A/C/I; RACI role IDs not R01...). | PROPOSED | 2026-10-08 (RACI review) |
| S19 | Running logs apart from the approved part: what changes with people (holders, releases) goes on dated, PI-initialed lines on a continuation sheet and does not require re-approving the fixed part. | PROPOSED | 2026-10-08 (RACI review) |
| S20 | Individual records (TRE, SCR) carry signature boxes for the assessor, the PI / accountable approver and the person assessed (TRE adds the supervisor). | APPROVED (author: "aprovo tudo", SCR review) | 2026-10-10 |
