A
Purpose and Use
Assess whether the site can implement the current sponsor-controlled imaging requirements and submit its evidence package for sponsor/CRO review. Site signatures attest this self-assessment. This record does not authorize activation, enrollment or imaging use.
ElementScope / DecisionRecord / Link
Unit of analysisOne site imaging requirement or linked readiness package for a defined source version.SIRR / Assessment ID; source version and effective date.
Decision supportedIs the local arrangement evidenced and ready for submission, with what limitations?H: site conclusion; J: separate external decision references.
InputsProtocol/CIP, sponsor charter/manual and controlled local evidence.D: source-to-workflow mapping; E–G: controls and routes.
OutputsMapped process, evidence, gaps/actions and controlled reassessment.IQL requirement links; accountable routes and reassessment in I.

C
Interface with IQL: Local Response Boundaries
These are pathway categories, not image-set decisions in the SIRR. Use the sponsor’s classification when different and map the local response. The IQL records each set and the applicable requirement/version.
Acceptable: Prepare the archive/transfer and review route for a complete, traceable set meeting the applicable requirements.
Limited: Define who records the limit, assesses its consequence and requests second review under the source rules.
Non-conforming: Define recovery/repeat feasibility, timing/clinical review and action/deviation referral.
Not assessable: Define evidence recovery and escalation when the image set, source or qualified review is unavailable.
