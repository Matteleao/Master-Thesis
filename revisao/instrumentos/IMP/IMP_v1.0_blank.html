A
Purpose and use

The IMP is the site's plan for checking its own work during the investigation, alongside the sponsor's monitoring. It is written and approved before the first participant is included. It does not record any review: each review is run and recorded in the Internal Monitoring Checklist (IMC), which cites the IMP version it followed.

For each of the ten checks the plan fixes, in advance, what is checked (C), when and by whom (D), on which records and how many (E), what counts as done, evidenced and effective (F), what calls a review early (G) and where each kind of result goes (H). Rules are set before results exist. A change applies only from its effective date onward and is entered in J; reviews already done stay with the version they used.
