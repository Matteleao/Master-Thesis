A
Purpose and use

The SCML indexes the site’s complications, adverse events, adverse device effects and device deficiencies so they can be compared across cases. Each case is assessed in the Safety and Adverse Effect Reporting Template (SART); the log keeps only the current classification and the links to its sources. Urgent care and safety reporting never wait for this log.

Unit of analysisDecision supportedInputsOutputs
One event, as assessed in its SART case.How the event is profiled for review across cases, and where its follow-up is sent.SART case and grade, Intraoperative Checklist and Device Log (ICDL), imaging source.Indexed events for the Complication Signal Surveillance Template (CSST); status for the PI Oversight Template (POT).

C
Event and Source Index

Enter one row per distinct event or deficiency. SART case ID / event reference links the row to its individual source. Use the same clinical term or study term/code as the source. Record the event date and days from the procedure; enter N/A when the interval does not apply. New information about an existing event updates that entry and its source link.
