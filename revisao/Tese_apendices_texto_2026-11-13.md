# Appendices

Every instrument was developed for shoulder device investigations. The description of the instrument set identifies the procedure-specific content and the structures that support adaptation to other surgical specialties while retaining the underlying logic. Blank and completed versions are available for every instrument. The appendices present examples completed with simulated data to illustrate how each instrument is used. Appendix Y provides access to the repository containing the blank versions.
