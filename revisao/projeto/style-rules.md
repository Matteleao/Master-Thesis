## Punctuation Conventions

| Element | Convention | Example |
|---|---|---|
| Quotation marks | Curly double quotes; single quotes only inside a quotation | “rapid adaptation” |
| Dash | No em dash and no en dash in prose. Ranges in prose use "to" | DR1 to DR12 |
| Ellipsis | Not used | |
| Serial comma | Yes | temperature, pH, and cell density |
| Semicolon | Only inside citation brackets or in list items that already contain commas. Elsewhere, a period | |
| Colon | Only before a list, example or definition that follows a complete statement | |
| Hyphen | Compound modifier before a noun (*site-level framework*); none after the noun (*at site level*). No hyphen after non, inter, intra, pre, post, re, sub, except established regulatory terms (*post-market clinical follow-up*) | nonhospital, interobserver, predefined |
| Numbers | Numerals for data, measurements and values with units (12 domains, 24 instruments, 89%). One to nine in words in general prose. Numerals throughout when small and large comparable values appear together. Never open a sentence with a numeral | Sixty of the 65 organizations… |
| Decimals and percentages | Decimal point; percent symbol | 27.7% |
| Citations | Vancouver, [n] in subscript, before the period (author, 28/10). Each reference is cited at its first appearance in each chapter; within the same chapter it is not repeated for a document already named in the text (ISO 14155:2026, ICH E6(R3), MDR…). An article whose claim is not attributed by name keeps its number where its claim is used | …was reported [12]. |
| Spelling | American English; proper names keep their official spelling | center, standardized; International Council for Harmonisation |
| Contractions, exclamation marks | None | |

## Writing Rules

| ID | Rule | Scope | ✅ Right | ❌ Wrong | Source |
|---|---|---|---|---|---|
| R1 | Plain B2–C1 prose with exact technical terms. No sentence that exists because it sounds good | all | None of the three instruments assigns the site an operational layer to carry these obligations. | What is missing is not a rule. It is a layer. | thesis-writing |
| R2 | Bind sentences that form a chain of consequence (because, so, and, therefore). Never three or more unconnected sentences in a chain | all | The clinical evidence becomes the clinical evaluation report, and the report becomes part of the file the notified body decides on. | The clinical evidence becomes the CER. The report becomes part of the file the notified body decides on. | thesis-writing |
| R3 | No *rather than* or any disguise: *X, not Y*; *not X but Y*; *it is not X, it is Y*; *instead of*; *and not* | all | Paper is the minimum medium the design assumes, and a site with an electronic system can carry the same structures. | Paper is the floor of the design, not its endpoint. | thesis-writing |
| R4 | Opposition construction only for a genuine conceptual distinction (e.g., sponsor-level vs site-level oversight); never twice in one section | all | | | thesis-writing |
| R5 | No self-commenting tail (*X, and this is…*, *X, which is the…*) when the second clause only comments on the first | all | The site holds no account, and no clause requires it to hold one. | The site holds no account, and this is the gap. | thesis-writing |
| R6 | No announcing opener: the paragraph starts with its substance | all | The literature review was narrative, so it maps the problem space and cannot show that a body of work is absent. | Three limitations apply to the work as a whole. | thesis-writing |
| R7 | No aphorism and no closing sentence that repeats the paragraph. A closing consequence is allowed | all | | Verification comes too late. | thesis-writing |
