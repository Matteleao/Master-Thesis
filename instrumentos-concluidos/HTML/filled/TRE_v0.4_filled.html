A
Purpose and Use of this individual record

This record follows one person through qualification, training, competence assessment and release to perform defined study tasks. It is completed for the person's actual role and the tasks that person is being considered for.

The training required for this person comes from the DTRM: the profile named in the header and the modules that apply to it, with the assessment method the DTRM states for each module that needs one. The evaluator records this person's evidence against that standard and does not define a separate catalogue.

The CCDM remains the source for the criticality code, supervision level and task boundary of each task. For surgical tasks, the SCR credentialing decision is a qualification prerequisite recorded in Section B. The release recorded in Section E, per CCDM task ID, feeds the RACI, which assigns a C2 or C3 task only to a person released here.
