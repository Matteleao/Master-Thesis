A
Purpose and Use

Record each required image set when it is acquired or first available, against the sponsor imaging charter or manual: timing, completeness, technical quality, the local use decision and where the images are kept.

Section C is the log: one row per set, on as many log sheets as needed. Sections D to G are completed once per review period and cover every set logged in it. The record that uses the set (PSEAR, ICDL or PFVR) keeps its consequence for the participant; the IQL keeps the technical assessment.

Unit of analysisDecision supportedInputsOutputs
One image set: one participant, one time point.Whether the set is complete, adequate and usable for its stated purpose.Imaging charter or manual; the images and their metadata; the linked PSEAR, ICDL or PFVR.Set status for the linked record; set counts for the FUCR and the PIR; routes for open issues.
B
Image-Set Classification Guide
Illustrations only, not acceptance thresholds. Apply the approved Imaging Charter/manual. Assess each dimension separately; these examples are a reminder, not fields to complete.
DimensionWhat to distinguishExample / recording reminder
TimingAssess acquisition against its applicable window; retain the actual date.Window ends 24 Sep; acquired 26 Sep: Outside. Later recovery does not make the original acquisition timely.
Set completenessCompare required views or sequences with what was actually acquired.Two of three required views: Partial. Technically clear images do not establish a complete set.
Technical qualityAssess positioning, coverage and other sponsor-defined technical criteria.All views present, but positioning limits assessment: Limited. No images available, or not yet reviewed: Not assessed (local use is then normally Pending).
Local use decisionRecord whether the set can support its stated local purpose, including any restriction.A necessary second review is outstanding: Pending. Not usable means the set was assessed and cannot serve its stated purpose. Limited use needs a documented permitted purpose; it does not establish central acceptance.
Set relationshipIdentify a repeat or supplemental set and link it to the original.A repeat gets a new Set ID and names the original in "Related set". The original entry, with its timing, stays as recorded.
